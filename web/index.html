工作区帮助

数据 · 文稿仅保存在本浏览器，不写回磁盘、不跨设备同步。关闭标签不会删除文稿；JSON 备份可导入合并。

快捷键 · Ctrl / ⌘ S 保存，Ctrl / ⌘ F 查找替换，F3 / Shift F3 切换匹配。刀轨支持滚轮 / 双指缩放、拖动平移，双击复位视图。

代码生成 · 内置单线字库仅支持英文、数字及部分标点，使用 Z 轴抬落笔。中文请导入外部 G-code；系统字体排版不是实际笔迹。

字形 · 活动栏「字形」管理字库（内置、服务器、导入到本浏览器），设置优先级与选字策略（固定 / 轮换 / 可复现随机），并为每个字选默认写法。在「纸张」页点击某个字可单独指定这一处的写法。缺字会以红色系统字体示意，且不能生成。

笔起点 · 在「书写设置」中设定笔的工件零点位于纸张哪个角、向内偏移多少，以及机器 +X / +Y 的方向。生成的 G-code 以该点为 (0, 0)；纸张页与刀轨页会标出零点。实际使用时把笔移到该点，再在「坐标定位」中 XY 置零。

坐标定位 · 连接后从活动栏读取机器 / 工件坐标。显示切换不写设备；G54–G59 切换与纸张 X/Y 设零需确认并读回。设零保存工件偏移，不移动机器、不改 Z，也不是设备回零。未知或过期读数显示 —。机器行程须在连接弹窗核对填写，允许负数，不能用纸张尺寸代替。点动、回零和安全返回原点待型号、限位及抬笔方式确认后接入。

设备 · 仅适配标准 GRBL 1.1，奎享具体型号兼容性待确认。模拟 / 应答进度、控制器报告位置均不是编码器实测位置；软复位不是物理急停，复位后须重新连接。

USB 控制器连接

USB 插在运行服务的电脑上，局域网设备通过本地桥接操作。当前驱动仅支持标准 GRBL 1.1；奎享是否兼容需先核实。

需要运行 server.py，静态文件服务不提供 USB 接口。
