# 字形库与选字格式（v1）

> 旧标识 `web-typewriter/glyph-library`（改名前）仍可导入。

目标：把「文字」与「每个字实际用哪一笔写法」关联起来，同时让字库来源可替换（内置单线字、服务器字库、导入 / 手写采集的字库）。

分两种数据：

| 数据 | 归属 | 存放 | 说明 |
|---|---|---|---|
| **字形库** `glyph-library` | 独立文件，可多份共享 | 内置 / `web/glyphs/*.json` / 浏览器 IndexedDB | 每个字的若干写法（变体）及笔画点序列 |
| **选字设置** `glyphs` | 每份文稿 | 工作区（随文稿保存、备份） | 用哪些字库、选字策略、每字默认写法、逐字指定 |

文稿只**引用**字库 ID 与变体 ID，不复制笔画，所以字库可以很大，文稿仍然很小。

---

## 1. 字形库文件

```json
{
  "format": "penfall/glyph-library",
  "version": 1,
  "id": "my-hand",
  "name": "我的手写体",
  "author": "",
  "license": "仅限个人使用",
  "description": "",
  "unitsPerEm": 1000,
  "glyphs": [
    {
      "char": "永",
      "variants": [
        {
          "id": "v1",
          "advance": 1000,
          "strokes": [
            [[120, 80], [130, 300, 0.6], [140, 520, 0.8, 35]],
            [[300, 200], [700, 210]]
          ],
          "tags": ["楷"],
          "source": { "device": "wacom", "capturedAt": "2026-11-09T10:00:00Z" }
        }
      ]
    }
  ]
}
```

### 坐标系

- 单位为 em 单位，`unitsPerEm`（默认 1000）对应文稿的「字高」。
- 原点在字身框**左上角**，x 向右，y **向下**（与书写排版方向一致）。字身框高 `unitsPerEm`；笔画可以略超出框，例如逗号下沿。
- `advance` 是这一写法的前进宽度（em 单位），不含字距。中文通常为 `unitsPerEm`，西文更窄。

### 笔画

- `strokes` 按**笔顺**排列；每一笔是一串点，落笔 → 依次连线 → 抬笔。
- 点格式为 `[x, y]`，可附带压力 `[x, y, p]`（0–1）和时间 `[x, y, p, t]`（相对本字第一点的毫秒）。目前生成路径只用 x、y；压力和时间留作以后调整速度、笔压使用，导入时保留。
- 单笔只有一个点时视为点画，生成时会落笔再抬笔。

### 约束（导入时校验，不合格整份拒绝）

- `id`：1–64 位，限 `a-z 0-9 - _ .`；`variants[].id`：1–32 位，限 `A-Z a-z 0-9 - _`。
- `char` 必须是**一个** Unicode 字符（码点）。同一字库内 `char` 不重复，同一字内变体 `id` 不重复。
- 每字最多 32 个变体，每个变体最多 64 笔，每笔最多 2000 点，整库最多 500 万点。
- 坐标必须是有限数，绝对值不超过 `unitsPerEm × 4`。

## 2. 文稿的选字设置

保存在每份文稿的 `glyphs` 字段：

```json
{
  "libraries": ["my-hand", "builtin-latin"],
  "strategy": "random",
  "seed": 20261109,
  "prefer": { "永": { "library": "my-hand", "variant": "v2" } },
  "pins": [ { "at": 12, "char": "永", "library": "my-hand", "variant": "v3" } ]
}
```

- `libraries`：启用的字库及**优先级**。某个字只从**第一个**含有它的字库取写法，避免同一行混用多种风格。
- `strategy`：没有指定写法时如何从该字的变体中选择：
  - `first`：总用第一个变体。
  - `cycle`：同一个字在文中依次轮换变体（第 1 次用变体 1，第 2 次用变体 2……）。
  - `random`：按 `seed` 伪随机选择。结果可复现：同一文稿、同一种子，每次生成都一样。点「换一批」即换种子。
- `prefer`：「这个字默认用哪种写法」，优先于策略。
- `pins`：「文中**这一处**的字用哪种写法」，优先级最高。`at` 为正文中的码点序号（从 0 开始），`char` 用于校验：编辑正文时会自动平移后面的指定；如果该位置的字已经变了，这条指定就作废，不会套到别的字上。

选字顺序：逐字指定（pins）→ 每字默认（prefer）→ 策略。被引用的字库或变体不存在时，退回到下一级；正文中有任何字在启用字库里都找不到，生成会被阻止并列出缺字，不会用系统字体冒充。

## 3. 存放与加载

- **内置**：`builtin-latin`（英文字母、数字、部分标点，单线），随代码提供，总是可用。
- **服务器字库**：放在 `web/glyphs/` 并登记在 `web/glyphs/index.json`，页面打开时读取列表，用到时再下载。
- **导入字库**：在「字形」面板导入 JSON，保存在当前浏览器的 IndexedDB（不占工作区 8 MB 配额）。可导出再分享。工作区备份**不包含**字库，需单独导出。

## 4. 手写板数据

手写板或采集软件导出的原始数据（InkML、SVG、厂商 JSON 等）通过转换器整理成本格式：归一化到 em 坐标、按笔顺分笔、平滑 / 抽稀，并保留压力和时间。拿到实际导出样例后，再为该格式编写转换器。
